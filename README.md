# Strave

Marketing site for Strave, built with Next.js (App Router), TypeScript and Tailwind CSS v4.

## Develop

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
npm run lint
```

## Structure

- `src/content/site.ts` — all copy, stats, nav links and logos (edit text here)
- `src/components/` — page sections (`Nav`, `Hero`, `Trusted`, `Background`)
- `src/components/showcase/` — the card row (phones, posts, stats, notifications)
- `public/images`, `public/logos` — static assets
